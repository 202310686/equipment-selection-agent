# 评测口径与结果边界

## 数据来源

内部评测使用客户需求清单作为题目、方案部人工成果作为参考答案。人工答案反映当时的选型，未必是唯一正确方案。

记录中的题数、有效行数会随时间、题目停用替换、产品库变化而调整。因此不同日期结果不能直接合并比较。

## 指标

| 指标 | 含义 | 限制 |
| --- | --- | --- |
| 候选 Top-1 命中 | 工具第一候选与参考型号相同 | 尚未经过模型最终决策 |
| 候选 Top-3 命中 | 工具前三候选包含参考型号 | 不代表最终选对 |
| 严格 | 最终型号与参考答案一致 | 可用的替代型号可能被判不一致 |
| 中档 | 型号一致或同小类 | 不保证全部需求参数满足 |
| 宽松 | 型号一致、同小类或同大类 | 不能等同可交付准确率 |
| 自检错误数 | 规则检查发现的硬错误 | 零错误只代表检查覆盖范围内未发现问题 |

对参考答案中停单、禁用旧系列、资料库查不到的型号，内部评分会剔除相应行。应同时披露分母与剔除规则。

## 同条件单题对照

依据内部记录，两版使用同一模型、同一混合系统需求清单，各执行一次：

| 指标 | 原版 | 优化版 |
| --- | ---: | ---: |
| 有效评分行数 | 27 | 27 |
| 严格 | 40.7% | 40.7% |
| 中档 | 74.1% | 85.2% |
| 宽松 | 81.5% | 88.9% |
| 自检硬错误 | 1 | 0 |
| 用时 | 615 秒 | 525 秒 |

中档提高 11.1 个百分点。用时减少 90 秒，约 14.6%。

这些是历史运行结果的文档摘要，未在本仓库重新运行，公开数据也不足以让第三方复算。

## 反例与限制

另一道会议扩声题，旧版历史产出中档为 85.7%，新版一次运行中档为 78.6%。两者模型与产出条件不同，不能作为严格对照，但足以提醒：不能声称所有题目都改善。

后续按更新产品库重判时，部分成绩发生变化。比较时应固定产品资料、经验库、评分程序和 Agent 版本。

项目尚无覆盖全部业务场景的、同条件多题重复运行结论。因此不将业务人员对原版的“六成左右”印象和新版部分题目的“八成左右”成绩拼接成总体提升。

## 防止答案泄漏

历史项目成果可能同时进入经验库与评测答案。应按项目排除测试题对应成果，隔离答案目录，并记录或恢复评测期间 Agent 写入的技能和记忆。

内部记录曾识别到答案泄漏，并将对应成绩排除于有效准确率结论。此类运行可用于分析耗时，但不能用于证明泛化效果。

## 后续验证方向

固定模型、资料和评分版本，对同一批题同时评测基线与优化版；保留失败及超时结果；重复运行，并由业务人员抽查参数满足和可交付性。文件生成、偏离表、文字方案等任务需要各自的评测。
